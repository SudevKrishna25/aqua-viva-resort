## 🌊 Overview

**AQUA VIVA** *(Living Water)* is an award-level luxury hospitality brand website and digital monograph conceptualised and engineered from scratch. Guided by the philosophy of **Mineral Modernism**, the experience unites contemporary architectural minimalism, raw natural materials, living water reflections, and cinematic editorial storytelling.

---

## 🎨 The Mineral Modernism Brand Palette

Strict adherence to the official six-colour Aqua Viva system:

- **SALT GLAZE** (`#CED4C1`) — Primary editorial background, honed travertine terraces, content canvases.
- **SHIPMATE** (`#77A2CB`) — Sky-inspired highlights, active states, water metrics, subtle glows.
- **EVERLASTING SAGE** (`#929687`) — Botanical surfaces, micro-labels, architectural divider lines.
- **KING TIDE** (`#2B737C`) — Primary ocean accent, reservation CTAs, interactive highlights.
- **HEAVY KHAKI** (`#5E6836`) — Endemic flora details, botanical highlights.
- **DARKNESS** (`#171C0E`) — Deep nocturnal canvases, monumental typography, footers.

## 🏛️ Digital Flagship Features

1. **Extended Cinematic Brand Overture:** Staged 6.5s brand overture with numerical calibration counter (`00%` → `100%`), fluid SVG waterline drawing, caustic light sweep, and expanding iris aperture transition.
2. **Asymmetrical Editorial Hero:** Monumental typography (*"WHERE WATER MEETS WONDER"*), Ken Burns slow parallax scaling, magnetic CTAs, and Web Audio API procedural ocean tide synthesis.
3. **The Residence Collection:** Detailed architectural monographs, specifications, materials, and floorplans for *The Water Villas*, *The Garden Residences*, and *The Horizon Suites*.
4. **Horizontal Discovery Track:** Pinned desktop horizontal scroll sequence with responsive vertical stack on mobile devices.
5. **Pinned Water Storytelling Chapter:** 5-scene narrative sequence celebrating elemental purity, cantilevered basins, and celestial horizons.
6. **24-Hour Chronology:** Interactive time selector with dynamic day-to-night background atmospheres and sensory notes.
7. **Curated Experiences:** 6 bespoke journeys ranging from solar-electric barrier reef charters to subterranean magnesium hydrotherapy.
8. **Visual Monograph Gallery:** Categorized collage with full-screen zoomable lightbox modal and keyboard navigation.
9. **Private Concierge Booking System:** Interactive residency enquiry modal with live validation and confirmation state.
10. **Full Mobile Optimization:** Handcrafted responsiveness across all phone and tablet viewports, touch-friendly navigation, zero horizontal overflow, and auto-zoom prevention.

## 🛠️ Tech Stack

- **Framework:** Next.js 14 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animation & Motion:** GSAP 3 (ScrollTrigger)
- **Smooth Scrolling:** Lenis
- **Audio:** Web Audio API (procedural ocean tide generation)
- **Icons:** Lucide React
- **Typography:** Instrument Serif, Cormorant Garamond, Manrope

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/SudevKrishna25/aqua-viva-resort.git

# Install dependencies
npm install

# Run the development server
npm run dev

# Build for production
npm run build
npm start
```
